# Event Attendance Analytics — planned

A future analytics case study based on **fictional registrations and check-ins**, focused on:
- registration-to-attendance conversion
- attendance by session and event date
- no-show and capacity KPIs
- QR check-in latency and data quality

This is a **project plan**, not a completed dashboard. It is intentionally separate from any private or institutional event information. The proposed source is generated demo data that does not represent actual attendees.
